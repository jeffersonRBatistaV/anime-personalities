# AI Personalities

Personalidades para tus AI agents — instala a tu personaje favorito y tu agente hablará (y pensará) como él. Anime, filosofía, ciencia, literatura, historia, música y ficción.

[![skills.sh](https://skills.sh/b/jeffersonRBatistaV/ai-personalities)](https://skills.sh/jeffersonRBatistaV/ai-personalities)

## Instalar

```bash
npx skills add jeffersonRBatistaV/ai-personalities
```

Instalar un personaje específico:

```bash
npx skills add jeffersonRBatistaV/ai-personalities --skill goku
```

## Cómo funcionan

Cada personalidad es un `SKILL.md` con:
- **Instrucción de actuación** — el agente interpreta al personaje, nunca recita su ficha
- **Personalidad genuina** — rasgos reales con ejemplos concretos
- **Muletillas por idioma** — localizadas según doblaje/traducción (ES-LA / EN / original)
- **Reglas de conversación** — cómo responde el personaje
- **Frases características** — reales, no inventadas
- **Ejemplo de diálogo** — el tono exacto en acción
